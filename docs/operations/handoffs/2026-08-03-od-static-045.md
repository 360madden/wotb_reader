## Key findings (11.19.0 Dead Rail, 4s window, 2,779 window measurements)

1. **replayTime delta marker is deterministic → the ideal filter.** The
   replay-time advance per window is exactly `window × speed` seconds, so the
   true field passes **100% of windows at every tolerance swept (0.2 / 0.4 /
   1.0 / 2.0 / 4.0s), survival 1.0 even over 15 rounds**. Decoys whose
   per-window advance differs shed immediately.
2. **Position delta marker is bursty → HOLLOW collapse.** At the OD-044
   recommended tolerance (2.4992) the pass-rate is only **0.8996** →
   survival **0.347 over 10 rounds / 0.205 over 15**. The tank stands still
   for much of the replay, so the TRUE position field produces ~0
   displacement windows that shed like decoys. A live Float pilot at this
   tolerance would collapse survivors but also shed the field.
3. **Speed marker is not selective** at usable tolerances (passes 1.0 only at
   tolerance ≥8× target).
4. **Pilot order flip:** run the Double replayTime delta pilot FIRST
   (`-ValueKind Double -CompareMode delta -DeltaTarget 4.0 -DeltaTolerance
   0.4`), then Float position on a movement-only window, then operator
   Find-what-writes. Unit variants for the unknown in-memory Double: 4.0s /
   4000ms / 4,000,000ticks.
