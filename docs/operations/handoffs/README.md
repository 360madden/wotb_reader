# Session handoffs

Each significant working session ends with a dated handoff record in this
folder, named `YYYY-MM-DD-<topic>.md`. The newest file by date is the current
handoff. Records are append-only history: correct a handoff with a dated
amendment or a superseding record, not by rewriting it.

Per the repository working agreements, every handoff reports:

- repository state (branch, head commit, working-tree cleanliness);
- changed files and public contracts;
- tests and validation commands run, with results;
- assumptions made and unknowns that remain;
- integration risks; and
- recommended next steps.

Do not record private replay paths, replay hashes, clan names, account
identifiers, chat, screenshots, credentials, or machine-specific secrets.
Player names and bot status are public Wargaming statistics and may be
recorded.
