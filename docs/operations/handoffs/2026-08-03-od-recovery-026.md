## Rules out / do not repeat

- **Do not repeat:** calibrating the steady-state gate to an assumed baseline
  (10M) — the gate must accept the measured stable baseline (66M this session)
  or it turns a survivable roll into a guaranteed failure (OD-026 attempt 1).
- **Do not repeat:** rolling a ~66M baseline with 8s transitions and the
  default 15-round limit — convergence does not fit inside the 120s lease
  (OD-025 attempt 1). Use 5s transitions and round limit ≥22 for large
  baselines. (Note: OD-025 attempt 1's exact discard trigger — lease expiry
  vs monitor health — was never conclusively pinned; its gate read Denied,
  not EvidenceStale. The correction that is well-evidenced is that baseline
  size was not the cause: 66M converges.)
- Automated CE Windows-debugger write-BPs stay ruled out (OD-020).
