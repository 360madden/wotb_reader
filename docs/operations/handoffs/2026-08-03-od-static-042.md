## Evidence produced (static, no game process)

- **`0x037F3054` = the shared RTTI `type_info` vftable** (refined from
  OD-041's "EH handler/funclet table" label):
  - Every TypeDescriptor's `pVFTable` points at it — confirmed
    `td@0x03DB5120` (`.?AU?$StaticAnyFnInvoker@V<lambda_0872e1a5…>@@PAV
    DebugEntitySkeletonComponent…`) has `pVFTable == 0x037F3054`.
  - Constructor at `0x020CB956` writes it to `[this]+0`
    (`c7 06 54 30 7f 03` = `mov dword ptr [esi], 0x037F3054`) — the
    canonical MSVC x86 vftable init, explaining the 48,609 `.data` refs.
  - Its slots point at EH funclet thunks (`lea r,[ebp+..]; jmp` at `.text`
    0x02CF0D70+) — type_info virtuals + EH funclets.
- **`--vtables` mode (new):** scans `.rdata` for runs of ≥N consecutive
  4-aligned dwords pointing into `.text` (vtable candidates), resolves each
  via `vtable[-1] → COL(+12) → td(+8 inline name)`.
  - **The fix:** MSVC x86 stores the mangled name **inline at `td+8`** (a
    `char[]`), not as a VA pointer. Named vtables went **0 → 17,133**.
  - Results: **18,721 vtables, 17,133 named, 2,615 `.data` roots.**
  - Chain-class hits: `GameScene` `0x0319D3C4` (26 slots, **0 `.data`
    roots** — honest negative for the vtable-singleton path),
    `BaseContext` `0x03197044` / `RootContext` `0x03197068`,
    `VehicleMovementFilterComponent` `0x03199C68`,
    `VehicleFashionComponent` `0x03199FF8`.
  - Component event table: `.data` `0x03B7E198..` holds consecutive vtable
    pointers → 44-byte vtables at `.rdata` `0x031988B4+`
    (StaticAnyFnInvoker lambda vtables for TankComponent/AimingPoint
    handlers).
- **Vehicle-family TypeDescriptor xref (ranked Track A step):** tds located
  (`VehicleGameLogicComponent` td `0x03C24F44`, `GameCameraComponent`
  `0x03C19E90`, `GameSceneController` `0x03F10644`, `AppContextImpl`
  `0x03E356EC`, VehicleDescr family) but **0 direct `.text` refs and 0
  `.data`/`.rdata` slots hold them** — `dynamic_cast`/`typeid` in this build
  does not emit direct absolute td operands; the RTTI name→root path is
  exhausted for the chain classes.
