# Repository Guidelines

## Project status

This project is at the initial scaffolding stage. Update this file as the architecture and development workflow become established.

## Working agreements

- Keep changes focused on the requested task.
- Preserve existing user changes and avoid destructive Git operations.
- Prefer small, reviewable commits with clear messages.
- Add or update tests when behavior changes.
- Keep secrets out of the repository; document required variables in `.env.example`.
- Update `README.md` when setup, build, test, or run instructions change.

## Validation

Before handing off a change, run the relevant formatter, linter, type checker, and tests once those tools are configured. Report any checks that could not be run.
